# 已定決策清單（使用者拍板）

- 系統：全面採用《月圓之夜》核心機制；捨棄 Gemini 的「連鎖返 1 法力」
- 世界觀：修仙；主角林琴／林劍（性別只影響外觀和稱呼）
- 劇情：簡化為單一主線；父親救得回來；真結局＝世界淨化、修仙回歸
- 流派：原創六流派（負山、留痕、折光、回瀾、枯榮、觀棋）；首發留痕、負山；第 1 章凡人卡組，章末選流派
- 主角自帶清氣，不會被邪毒污染
- 留痕：痕上限 4；有牌可提高本場戰鬥痕上限；腐化留痕敵人回合開始回復等於痕數的生命，並會對玩家刻痕
- 命名：卡牌古典；人物可玄幻、搞笑、混現代
- 敵人與主角一樣有生命、真氣、行動力
- 資源名：真氣（＝月圓的法力）
- 貨幣：全程使用「銀兩」（＝月圓的金幣），不改靈石
- 開發順序：先做第 1 章文字版 demo（demo/ch1_demo.html）
- 留痕：痕滿後再刻痕觸發「爆痕」，造成等於當前痕上限的傷害，痕歸零（取代溢痕）
- 生命：主角初始生命 20；玩家沒有回血牌，只有事件會少量回血；升級時回滿生命並提高生命上限；敵人輸出不因初始生命下調而降低
- 地圖（仿月圓）：首領頁一出現就可以直接選，打完進下一章；不選就能把本章其他書頁全走完，最後只剩首領
- 回血卡：第二章才出現；第一章只有事件少量回血
