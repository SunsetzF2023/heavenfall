## 3. 武道大比擴寫

現流程：選書頁 → 直接拜師選流派 → 趙鐵柱。太快，擂台沒有「賽事感」。

### 新流程
```
武道大比（書頁）
  → ① 報名處：主持人吆喝介紹（lore：武道界、極武閣）
  → ② 初選賽：打「落魄拳師」（新敵人，見下）
  → ③ 拜師選流派（原有，加戲：沒被選的師父說一句風涼話）
  → ④ 師父贈禮：選定流派後，師父私下給 1 張該流派兵器（留痕→刻刀，負山→重盾，直接進牌組）
  → ⑤ 賭坊開盤（新事件）：賭自己贏，押 X 銀兩（10 起押，封頂 30），贏了 1.5 倍返還
  → ⑥ 決賽：趙鐵柱（原 bossIntro，加賭注結果結算）
```

### 新敵人：落魄拳師（初選賽）
| 欄位 | 值（暫定） |
|---|---|
| 名稱 | 落魄拳師 周通 |
| lv / hp / ap / qi / draw | 3 / 22 / 1 / 1 / 2 |
| 牌組 | 重拳、橫掃、格擋、吆喝、運氣（全為已有牌） |
| intro | 「連輸三屆了。這一屆，總該輪到我了吧……小兄弟，對不住了。」 |
| 戰後事件 | 周通苦笑：「又輸了。」選項：①「明年再來。」（道心 +1，他塞你 5 銀兩「幫我買壺酒」）②「承讓。」（武魄 +1） |
| 設計意圖 | 給第一章加一個「可敬的對手」，也替趙鐵柱的「拳頭就是道理」做反襯 |

### 沒被選的師父風涼話
- 選留痕後，石敢當：「哼，玩刀的。哪天被砍了別說我沒提醒。」（他嘟囔著把一塊石碑扛走了）
- 選負山後，蘇小刀：「搬家的？行吧，練好了去給我理髮店搬椅子也算學有所成。」

### 趙鐵柱加戲
- 開場多一句按 flags 的差異：打過周通 → 「周通都打不過我的人，每年都有。」；快速通道直達 → 「喲，直接保送決賽的？有後台啊。」（快速體驗玩家的彩蛋）
- 戰後文本不動（結局銜接已好）。
