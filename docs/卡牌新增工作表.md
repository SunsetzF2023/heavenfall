| 關鍵詞 | 含義 | 月圓對應 |

| ×N | 多段攻擊（每段獨立判定） | 多次攻擊 |
| 抽 N 張 | 補手牌 | 抽牌 |

| 刻 X 痕 | 留痕流派專用；滿 4（或上限）再刻=爆痕，造成痕上限傷害並清零 | — |
| 斬 | 結算並清除目標的痕 | — |
| 崩 | 消耗全部護甲 | — |
| 暗置 | 反制牌打出後蓋放，敵人打武技時觸發 | 反制 |
| 移除 | 本場戰鬥打出後從牌庫移除 | 移除 |
| 敵人下回合行動力 -1 | 牽制效果 | — |

| 需條件 req | 打出前置條件（如「痕滿才能打」） | — |

## 參考：月圓之夜常見機制 → 本遊戲寫法

- 「抽牌直到手牌滿」→ 抽 X 張（X 自定）
- 「造成傷害等於手牌數」→ 造成 1 傷害 ×X（X＝手牌數），參考【王八拳】
- 「複製手牌一張」→ 目前沒有複製機制，要加的話在這裡備註「新機制」
- 「回復生命」→ ⚠️ 已拍板：第一章只有事件少量回血，回血牌第二章才出現
- 「法術反制/無效對方」→ 反制・暗置
- 「裝備：每回合……」→ 兵器 eq 掛鉤
